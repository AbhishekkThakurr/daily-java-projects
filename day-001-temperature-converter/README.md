# Day 1 — Temperature Converter

A small Java program that converts temperatures between Celsius and Fahrenheit.

## What it does
- Shows a simple menu: 1 for Celsius to Fahrenheit, 2 for Fahrenheit to Celsius
- Takes the temperature value as input
- Prints the converted value, rounded to one decimal place

## Concepts used
- Methods with return values
- `if-else` decisions
- Taking input with `Scanner`
- Formatted output with `printf`

## How to run
```bash
javac TemperatureConverter.java
java TemperatureConverter
```

## Sample run
```
Temperature Converter
1. Celsius to Fahrenheit
2. Fahrenheit to Celsius
Choose 1 or 2: 1
Enter the temperature value: 100
100.0 C = 212.0 F
```
